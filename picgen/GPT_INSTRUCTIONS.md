# Picture instructions for ChatGPT

> **ChatGPT: if you are reading this file, the user wants you to follow these instructions now.**
> Talk to the user in Chinese (简体中文). Follow the workflow below exactly.

These are illustrations for 49 French vocabulary words in a quiz app. For each word there is an example
sentence, and the picture must show **that sentence**, so that the meaning of the word is the focal point of
the image. The user will save each image and upload it into the app under the given file name.

## Workflow

1. **Start immediately.** Begin with item 1, unless the user's message names another number
   (e.g. “从 12 开始”), in which case start there. Do not ask for confirmation first.
2. **Exactly one image per reply.** Generate the picture for the current item, in landscape format
   (1536×1024, 3:2). Never put two items in one image, never skip an item, never change the sentence.
3. **After each image**, write exactly one short line in Chinese, in this form:
   `第 N/49 张 · 单词 · 文件名 ex-xxx.jpg — 保存后上传到工作台的这张卡片。回复“继续”画下一张，“重画”重新画这张。`
4. **User commands** (Chinese or English):
   - `继续` / `next` → the next item.
   - `重画` / `redo` (optionally with notes, e.g. “重画：猫再大一点”) → the same item again, applying the notes.
   - a number, e.g. `17` → jump to that item.
   - `跳过` / `skip` → move on without drawing the current item.
5. After item 49, say in Chinese that all pictures are done.

## Style — apply to every image

Flat vector cartoon illustration in a playful picture-book style: bold simple shapes, clean dark outlines, bright saturated colors, soft flat shading, uncluttered background. One clear focal action that tells the whole story at a glance, with expressive faces. Landscape format, 3:2 (1536×1024). Absolutely no text, letters, numbers or logos anywhere in the image.

Also:

- Keep the same art style, line weight and colour palette across the whole series, as if one illustrator drew them all.
- The key action described in the scene must be large, central and readable on a small phone screen.
- No text of any kind: no letters, words, numbers, labels, logos or watermarks. If a sign or tag is needed, use a symbol only.
- Cartoon characters only; no real, identifiable people and no brands.
- Friendly, kind humour; nothing frightening, violent or embarrassing for real groups of people.

- **Sentence:** Le cambrioleur s'est trompé de maison : c'est le commissariat ! — *The burglar got the wrong house: it's the police station!*
- **Scene:** At night, a burglar in a striped shirt and eye mask climbs a ladder and peers through a lit window, only to find a stern police officer with folded arms waiting inside. The building has a blue police light on the roof and police cars parked outside.
- **Must be obvious:** 他翻窗没错，错的是“选的那一个”：se tromper de + 名词（不加冠词）= 弄错。

### 49. prévenir — `ex-prevenir.jpg`
