# 选择题练习

按教材章节组织的单项选择题，每题有提示和解析。纯静态网页，用 GitHub Pages 发布，打开网址就能做，不需要登录。

- `french/`：法语语法（按《Advanced French Grammar》章节），含听力辨音、B1 模拟卷、背单词。
- `stoch/`：随机分析（Le Gall《Brownian Motion, Martingales, and Stochastic Calculus》）与概率论（Pascucci《Probability Theory I》）。

题目和知识点卡片是根据教材内容改写的练习题，不包含教材原文。

## 说明

- 答题进度、错题本、学习模式的开关都保存在浏览器的本地存储里：换设备或清除浏览器数据后不会保留。
- 听力题用设备自带的法语语音朗读（Safari / Chrome 都支持）。
- 公式用 MathJax 渲染（从 cdnjs 加载）。
- 法语模拟卷的作文没有自动批改，页面会给出范文和评分档次。

## 发布

仓库 Settings → Pages → Build and deployment 选 “Deploy from a branch”，分支选 `main`、目录选 `/ (root)`，保存后约一分钟生效，网址是 `https://<用户名>.github.io/quiz/`。
